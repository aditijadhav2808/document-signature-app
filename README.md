\# Document Signature App



\## Overview



Document Signature App is a web-based application built using FastAPI and React that allows users to upload PDF documents, manage signatures, approve or reject signature requests, and generate signed PDF files.



\## Features



\* User Registration and Login

\* JWT Authentication

\* Upload PDF Documents

\* View Uploaded PDFs

\* Manage Signatures

\* Approve / Reject Documents

\* Generate Signed PDF

\* SQLite Database Integration

\* Responsive User Interface



\## Tech Stack



\### Backend



\* FastAPI

\* SQLAlchemy

\* SQLite

\* JWT Authentication

\* PyMuPDF



\### Frontend



\* React

\* Vite

\* JavaScript

\* CSS



\## Installation



\### Backend



bash

cd backend

pip install -r requirements.txt

uvicorn main:app --reload





\### Frontend



bash

cd frontend

npm install

npm run dev
